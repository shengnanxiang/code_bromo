## 1. 产品概述

### 1.1 一句话定义

一台以经典胶片机的质感与节奏，让人重新认真拍照的数码相机。

### 1.2 产品愿景

在拍照变得无限、免费、即时的时代，"认真拍一张"反而成了稀缺体验。Bromo 为每一个愿意认真拍照的人提供更有质感的仪式感，和更完整的自由。

### 1.3 核心价值

| 价值 | 说明 |
|------|------|
| **经典质感** | 经典旁轴形态、金属机身，拨杆过片、机械节奏——拿在手里是器物，不是玩具 |
| **完整的胶卷体验自由** | 36张一卷，装卷出门、多卷连续拍摄、回家统一冲扫。保留胶卷时代的完整仪式 |
| **大底直出氛围感** | 1/1.56" 50MP 四合一传感器、自动对焦、氙气补光，承袭全系风格滤镜 |
| **数码内核的便捷** | 1秒开机，半按对焦、自动曝光；数字胶卷 Type-C 直插手机冲扫 |

### 1.4 与 AiKen 的关系

| | AiKen（一代） | Bromo（二代） |
|---|---|---|
| 定位 | 入门尝鲜 | 质感升级 |
| 价位 | ¥699 | 999-1299 |
| 形态 | 110 轻便随行 | 经典旁轴 |
| 传感器 | 1/3" | 1/1.56"（更大底） |
| 一卷张数 | 24张 | 36张 |
| 存储 | 内置128MB（一卷） | 数字胶卷仓（约10卷） |
| 连续拍摄 | 拍满必须传输 | 多卷连续，回家统一冲扫 |
| 对焦 | 泛焦 | 自动对焦（AF） |
| 闪光灯 | 无 | 弹出式氙气闪光灯 |

## 2. 目标用户与场景

### 2.1 核心人群

**一句话：愿意认真拍照的人。**

| 人群 | 特征 | 痛点 |
|------|------|------|
| **AiKen 升级者** | 已被 AiKen 打动，想升级质感与拍摄自由 | 画质底子有限；塑料质感"不够相机" |
| **经典质感情怀者** | 30-50岁，胶片时代成长，有摄影记忆 | 真实胶卷成本高、冲扫麻烦；现代相机复杂 |
| **氛围感追求者** | 18-30岁，追求风格化直出与社交分享 | 手机拍照不够特别；胶片门槛高 |
| **胶片尝鲜者** | 对胶片美学好奇，未入坑或浅尝辄止 | 试错成本高、技术门槛、等待周期长 |

### 2.2 核心场景

- **周末扫街 / 城市漫游**：一个下午拍数卷，装一卷数字胶卷出门，回家统一冲扫
- **旅行**：多卷连拍记录全程，回家整理冲扫
- **聚会 / 社交**：氙气闪光灯覆盖暗光室内
- **探店 / 看展**：风格直出，拼贴分享
- **日常随拍**：巴掌大小，挂带出街，拿出手是有质感的配饰

## 3. 核心体验原则

### 3.1 四大设计原则

1. **机械诚实**：约束必须是真的，效应才会发生。拨杆、弹钮、快门都是物理事实，不是屏幕提示
2. **一卷一调**：36张一卷，一卷一种风格。拍摄时专注，后期可反悔
3. **无屏盲拍**：无预览、无修图、无数字焦虑。每次拍摄都是决定
4. **回家冲扫**：出门不碰手机，拍摄与揭晓分离

### 3.2 与数码手机的区隔

|      | 手机   | Bromo     |     |
| ---- | ---- | --------- | --- |
| 拍摄节奏 | 无限连拍 | 逐张过片，郑重决定 |     |
| 风格选择 | 逐张可调 | 一卷锁定，后期可改 |     |
| 回看   | 即时可见 | 盲拍，回家冲扫揭晓 |     |
| 存储   | 无限   | 36张一卷，有边界 |     |
| 操作   | 触屏   | 机械拨杆、物理按键 |     |

## 4. 硬件定义

### 4.1 卷系统

卷系统是 Bromo 的核心差异化模块，定义"一卷一调"的完整体验。

#### 4.1.1 "卷"的定义与哲学

**卷**：一次装卷（闩合）到弹出之间的拍摄会话。

- 一卷固定 36 张
- 一卷锁定一种风格（暖调/冷调/灰调）
- 一卷是一个数据目录，文件编号在卡内顺延
- 满卷弹出后不换胶卷、直接再按下 = 同一张胶卷上开启新卷（多卷共存）

**卷的哲学**——卷不是对存储容量的妥协，而是拍摄行为的组织方式：

| 价值       | 说明                                |
| -------- | --------------------------------- |
| **决策成本** | 每按一次快门都是决定；第33张之后剩下的三格，逼你抬手之前想半秒  |
| **有始有终** | 卷会结束，结束催生回顾、导入、筛选——导出一卷是一次事件，不是杂务 |
| **风格承诺** | 一卷一调，拍摄时专注；后期可反悔（App重选风格、多风格冲印）   |

数字胶卷归还了 AiKen 因存储约束丢掉的两个胶片仪式——**装卷仪式**与**"带备用卷出门"的自由**，同时把冲扫改回真实胶片时代的行为模型：出门不碰手机，回家统一冲扫。

#### 4.1.2 状态机

**弹钮双态**：

```
┌─────────┐     按下（胶卷在位）    ┌─────────┐
│  弹起   │ ─────────────────────→ │  闩下   │
│ (自由)  │ ←───────────────────── │ (锁定)  │
└─────────┘    弹出（四种触发源）    └─────────┘
```

**弹起态（自由）**：
- 拨轮可转动，选风格（三档自由切换）
- 拨杆无效（离合脱开）
- 快门锁死
- 计数器 = 0

**闩下态（锁定）**：
- 拨轮锁死（沉入顶面，几何锁定）
- 拨杆有效（离合吸合）
- 快门待发
- 计数器随拨杆递增

**卷生命周期**：

```
装数字胶卷 → 拨轮选风格 → 按下弹钮 → 开卷（计数器=0）
  → 拍摄（拨杆过片 → 快门释放）×36
  → 第37次拨杆 → 满卷弹出（拨杆行程中段卸力）
  → 或卷终钮 → 主动弹出
  → 或开胶卷仓盖 → 取卷弹出
  → 弹起 → 拨轮解锁 → 可选换风格 → 按下 → 新卷
```

#### 4.1.3 四大触发源（弹出弹钮）

| 触发源 | 机制 | 供能 | 场景 |
|--------|------|------|------|
| **满卷脱扣** | 计数轮36位凸轮踢脱扣杆 | 手指（拨杆行程） | 一卷拍完 |
| **门联动** | 胶卷仓盖凸轮顶开锁闩 | 弹簧 | 取卷、换卷、看一眼 |
| **卷终钮** | 手动踢闩 | 手指 | 主动结束一卷 |
| **在线拒绝** | 电磁铁脉冲踢回 | 电子 | 无胶卷/容量不足按下时 |

**闩锁是单一汇聚点**：四个触发源共享同一闩锁，弹出沿 = 关卷是统一数据事件。

#### 4.1.4 闩锁架构

**架构原则**：分离的输入件 + 汇聚的闩。弹钮/拨轮、过片拨杆、仓门、卷终钮是各自独立的结构件（拨杆与拨轮互不嵌套），所有交互通过传信机构（推杆、凸轮、爪）汇聚到闩这一个点——**一个点、四个输入、一个输出，是复杂度最低的配置**。新增零件约六件（闩、脱扣杆、离合爪、门凸轮、卷终钮、电磁铁），全部是钟表级标准工艺，无一项需要发明。

```
        ┌─────────────┐
        │    闩锁      │
        │  （单一点）   │
        └──────┬──────┘
               │
    ┌────┬────┼────┬────┐
    ↓    ↓    ↓    ↓    ↓
  满卷  门   卷终  在线  拨杆离合
  脱扣  联动  钮   拒绝   ↓
                           快门待发
```

**闩锁状态**：
- **闩下**：离合吸合，拨杆有效，快门待发
- **弹起**：离合脱开，拨杆无效，快门锁死

**脱扣机构（满卷弹出）**：

```
第37次拨杆 → 计数轮36位 → 凸轮顶脱扣杆 → 踢开闩锁
  → 弹钮弹出（弹簧储能释放）
  → 离合脱开 → 拨杆行程中段卸力
  → 计数器归零
```

**关键设计**：弹出动能来自拨杆行程（手指供能），不是电磁铁。电磁铁仅用于在线拒绝与开机对账——**计划内的状态变更全部机械完成，断电可用**。

**门联动正阻挡**：开门时挡块进入按钮行程路径，物理不可闩——"闩下 = 胶卷被封在机内"由机构保证，开机、关机都成立。

#### 4.1.5 换卷弹钮 + 风格拨轮

| 参数 | 规格 |
|------|------|
| 直径 | 10mm（参照胶片机快门键） |
| 弹起高度 | 5mm左右（公差后期结合手板调整确定） |
| 按下深度 | 沉入顶面约1mm |
| 档位 | 3档（暖调/冷调/灰调），120°等分 |
| 刻度 | 红色刻线（刻槽填漆），对应顶面印刷图标 |
| 表面 | 滚花侧壁（弹起时可见可操作，拧表冠手感） |

**轴向两态 × 旋转三档**：
- 轴向两态：弹起高位（5mm，可旋转）↔ 按下低位（沉入顶面约1mm，不可旋转）
- 旋转三档：暖调/冷调/灰调，120°等分，仅弹起态可转（"三节"即三个旋转档位）
- 沉入后红刻线与顶面图标依然可视——整卷拍摄期间顶面一直读得出"这卷是什么调"

**锁定机制（已确认）**：
- 按下后拨轮沉入顶面，滚花侧壁全部低于表面，手指无法施力——**几何锁定，无额外锁止机构**
- 弹起态无锁，用户可随时在三档间自由旋转切换
- 换卷弹钮 = 风格拨轮 = 卷状态件：一个零件，三种身份

**安装拓扑（两案待选，建议方案A）**：

| 方案 | 结构 | 权衡 |
|------|------|------|
| **A. 表冠式·一体旋转** | 弹钮+拨轮整体旋转，闩锁卡旋转对称的环形槽，任意档位均可闩住 | 零件最少；手表表冠同构，量产验证充分；锁舌需配环形槽 |
| **B. 帽转芯定·分离式** | 旋转体与内部柱塞分离，柱塞不转，闩锁卡柱塞普通锁槽 | 锁舌结构常规；多一对转动界面，零件+1，有旷量风险 |

#### 4.1.6 过片拨杆

| 参数 | 规格 |
|------|------|
| 位置 | 机身右侧（右手拇指位），独立结构件 |
| 行程 | 与快门释放1:1互锁 |
| 离合 | 弹起时脱开（保留20-30%恒定阻尼，手感读作"脱开"而非"脱落"） |
| 卸力 | 满卷弹出时，拨杆在行程中段卸力 |

**1:1过片互锁（已确认需要，机械实现待设计）**：
- 拨杆行程与快门释放严格1:1互锁
- 快门未释放前，拨杆锁死（防重拍）
- 拨杆未到位前，快门锁死（防漏拍）
- 这是计数器正确性与防重拍的共同前提，对应胶片机的双曝预防机构

**离合细节**：采用任意相位可安全脱开的结构（球式棘爪类）——取卷或满卷弹出发生在拨杆行程中段时不卡死。

#### 4.1.7 卷终钮

| 参数 | 规格 |
|------|------|
| 位置 | 顶面，风格拨轮/换卷弹钮旁（暂定，ID布局与手板验证） |
| 操作 | 小凹钮，需指甲或笔尖按压，防误触 |
| 机制 | 纯机械，直接踢闩（第四个触发源） |

**行为**：

```
按下卷终钮 → 踢闩 → 弹起（离合脱开、快门锁死、计数器归零）
  → 拨轮解锁，可换风格
  → 按下弹钮 → 新卷
```

**设计规则**：开卷要容易，合卷要郑重，误合要不可能。误按的最坏后果是卷被切成两段（数据无损，5mm弹起当场可见），凹沉设计让概率趋近于零。

**边界情况**：
- **0帧合卷**：产生空卷，App侧不显示，机构不特判
- **不满卷结束**：数据无损，卷内照片完整保留
- **关卷原因**：元数据记录弹出原因（满卷/手动/取卷），Contact Sheet可显示"12张·手动合卷·暖调"

#### 4.1.8 数字胶卷仓

**概念**：把TF卡重新定义为"数字胶卷（Digital Film）"——胶卷罐造型的存储容器（内含TF卡槽的读卡器），自带弹出式Type-C公头。插进相机是"装卷"，取出直插手机是"送冲"。

> **设计哲学**：胶卷体验的灵魂不在介质，在行为。守住的是仪式，不是介质洁癖。

**实体形态**：

```
数字胶卷（配件产品线）
├── 胶卷罐造型外壳（注塑 + CMF，可做配色/联名收藏款）
├── TF卡槽（含卡，容量约10卷/360张）
├── USB桥接IC（Type-C U盘成熟方案）
└── 弹出式Type-C公头（平时收纳于罐体内，取出后弹出直插手机）
```

**使用流程**：

| 场景 | 操作 | 体验 |
|------|------|------|
| 装卷 | 数字胶卷插入相机胶卷仓 | 相机识别"新胶卷已装入" |
| 拍摄中 | 拍满36张弹出，再按下开新卷 | 同卡第二卷，或换胶卷 |
| 多卷管理 | 最多存约10卷（360张） | 一次周末扫街的完整容量 |
| 送冲 | 取出胶卷，弹出Type-C公头，直插手机 | 物理连接，比无线更快更稳 |
| 冲扫 | App自动识别胶卷内容，多卷列表逐卷处理 | 选风格 → 冲扫 → 揭晓 |
| 冲扫后 | 对应卷的空间释放，胶卷可复用 | 数字胶卷是可复用配件，非一次性耗材 |

**相机侧胶卷仓**：
- 专用连接器 + 仓体结构；电气上经胶卷内的USB桥接访问TF卡——相机视角下，数字胶卷就是一个U盘
- 仓盖机械联动：开盖必弹起（凸轮顶闩）、闩下时正阻挡——与TF卡仓门方案同构复用，无需独立设计
- 在位检测：机械在位开关（开关量，固件读取；在位≠可读，读写故障按"卡壳的卷"处理：报错不自动弹，出路是开门）

#### 4.1.9 断电与开机对账

**开机对账表**：

| 开机读到 | 胶卷状态 | 动作 |
|----------|--------|------|
| 闩下 | 无胶卷 | 脉冲弹起（在线拒绝路径） |
| 闩下 | 有胶卷 | 对账：续拍或开新卷（见下） |
| 弹起 | 有胶卷 | 待闩，按下开新卷 |
| 弹起 | 无胶卷 | 待闩，按下会被顶回（在线拒绝） |

**续拍规则**（"闩下 + 有胶卷"）：
- 断电期间未发生弹出（按钮一直闩着）→ 续拍，计数器接着走
- 任何弹出（包括断电时开门看一眼）都归零计数器 → 再闩合 = 新卷——**"开门即卷终"无例外**
- 判别方式：弹出必归零计数器，开机以计数器读数与卡上卷帧数对账（需给计数轮加静态读取触点，成本为几个触点；若不做读出，退化为拨轮档位令牌近似，同档位"看一眼"不可区分，语义上仍可辩护为续拍）
- 断电期间按钮一直闩着 → 拨轮物理上不可能被转过 → 档位必然一致 → 关机过夜再开机必然续拍，**卷不会因关机碎成多截**

**权威来源**：

| 状态 | 权威来源 | 说明 |
|------|----------|------|
| 弹起/闩下 | 机械闩锁 | 断电不变 |
| 计数器 | 机械计数轮 | 断电不变（几何位置，非内存），弹出归零 |
| 风格档位 | 拨轮几何位置 | 闩下后不可变 |
| 胶卷在位 | 机械开关 | 开关量，固件读取 |

**不变量**：
- **闩下 ⇒ 胶卷被封在机内**（门互锁正阻挡保证）
- **弹起 ⇒ 计数器 = 0**
- **闩下 ⇒ 风格档位不可变**
- **弹出沿 = 关卷**（数据事件）
- **闩合沿 = 开卷并采样风格**（数据事件）

### 4.2 影像系统

#### 4.2.3 对焦体验

- **半按对焦**：半按快门自动对焦，合焦后绿灯常亮
- **听觉反馈**：合焦"滴"一声（可关闭）
- **逻辑保护**：未合焦时快门锁死或继续拉焦；近距过近不释放

#### 4.2.5 风格滤镜

## 5. 数据模型与容量策略

### 5.1 卷目录结构

```
DCIM/
  └── ROLL_001/
      ├── 0001.jpg
      ├── 0002.jpg
      ├── ...
      └── 0036.jpg
  └── ROLL_002/
      └── ...
```

- 每卷一个目录，编号顺延
- 卷头记录：闩合时间戳、风格档位（拨轮采样）
- 卷尾记录：弹出原因（满卷/手动/取卷）、时间戳

### 5.2 文件编号

- 卡内全局顺延，不因卷而重置
- 旧卷/换卡插入：新建卷目录，编号继续
- 满卷弹出后不换卡直接再按下 = 同卡第二卷，与"换卡开新卷"同一条代码路径

### 5.3 风格元数据

- 闩合沿采样拨轮档位，写入卷头
- JPEG 不烧滤镜，仅标记默认风格（曝光/白平衡烧死，风格可反悔）
- App 导出时允许重新选择风格
- 同一张图允许多风格冲印

### 5.4 容量策略

**预留制**：
- 闩合时固件检查：剩余空间 ≥ 单帧最大体积 × 36 + 余量
- 不足 → 闩合后弹出（在线拒绝），提示"胶卷容量不足"
- 保证卷不会中途因容量失败——**一卷到底是契约，没有残卷**

**最坏帧体积**：
- 已确认：单帧最大按 2MB 计算，一卷预留 2MB × 36 + 余量 ≈ 75-80MB
- 备注：v0.3 估算单张约 2.5-4MB（12.5MP binned），2MB 偏紧；但数字胶卷 8GB 级容量、卷数上限约 10 卷（满载约 1-1.5GB），余量 5 倍以上，预留检查实际难以触发——该参数不敏感，实测后校准即可

**满载处理**：
- 满载（约10卷）后的按下 → 在线拒绝，提示容量不足
- 换胶卷路径与换卷同构：开门 → 弹起 → 换胶卷 → 关门 → 按下 → 新卷

## 9. 工程难点

| 难点 | 说明 | 风险 |
|------|------|------|
| **1:1过片互锁** | 拨杆与快门严格互锁，防重拍防漏拍 | 高（已确认需要，需新增设计，首要工程难点） |
| **计数轮凸轮精度** | 36位凸轮要准，35位误脱=丢一帧，37位才脱=用户困惑 | 中 |
| **脱扣力矩** | 释放闩锁需顶住弹簧力，安排在拨杆力矩峰值段 | 中 |
| **旋转基准统一** | 拨轮、顶板、定位盘共用旋转基准，防系统性偏移 | 中 |
| **计数器读出触点** | 开机对账需判别"断电期间是否弹出"，计数轮加静态触点 | 低 |
| **刻度耐久** | 红线刻槽填漆，顶板图标同样处理 | 低 |
| **门联动正阻挡** | 开门时挡块进入按钮行程路径，物理不可闩 | 低 |
