# 卷系统结构设计说明

> 版本：v1.0
> 日期：2026-11-23
> 范围：过片拨杆、快门、换卷弹钮+风格拨轮、TF卡仓

---

## 1. 核心概念

### 1.1 "卷"的定义

卷是相机的一次拍摄会话。一次装卡、按下弹钮、到弹起之间的所有拍摄构成一卷。

- 一卷固定 36 张
- 一卷锁定一种风格（暖调/冷调/灰调）
- 一卷是一个数据目录，文件编号在卡内顺延
- 卷与卷之间在数据侧连续，在体验侧分明

### 1.2 "卷"的哲学

卷不是对存储容量的妥协，而是拍摄行为的组织方式。它提供：

- **决策成本**：每按一次快门都是决定
- **有始有终**：卷会结束，结束催生回顾与筛选
- **风格承诺**：一卷一调，拍摄时专注，后期可反悔

## 2. 状态机

### 2.1 弹钮状态

```
┌─────────┐     按下（卡在位）      ┌─────────┐
│  弹起   │ ─────────────────────→ │  闩下   │
│ (自由)  │ ←───────────────────── │ (锁定)  │
└─────────┘    弹出（四种触发源）    └─────────┘
```

**弹起态（自由）**：
- 拨轮可转动，选风格
- 拨杆无效（离合脱开）
- 快门锁死
- 计数器 = 0

**闩下态（锁定）**：
- 拨轮锁死（沉入顶面，不可转动）
- 拨杆有效（离合吸合）
- 快门待发
- 计数器随拨杆递增

### 2.2 卷生命周期

```
装卡 → 拨轮选风格 → 按下弹钮 → 开卷（计数器=0）
  → 拍摄（拨杆过片 → 快门释放）×36
  → 第37次拨杆 → 满卷弹出
  → 或卷终钮 → 主动弹出
  → 或开门 → 取卡弹出
  → 弹起 → 拨轮解锁 → 可选换风格 → 按下 → 新卷
```

---

## 3. 四大触发源（弹出弹钮）

| 触发源 | 机制 | 供能 | 覆盖场景 |
|--------|------|------|----------|
| **满卷脱扣** | 计数轮36位凸轮踢脱扣杆 | 手指（拨杆行程） | 一卷拍完 |
| **门联动** | 门凸轮顶开锁闩 | 弹簧 | 取卡、换卡、看一眼 |
| **卷终钮** | 手动踢闩 | 手指 | 主动结束一卷 |
| **在线拒绝** | 电磁铁脉冲踢回 | 电子 | 空卡/满卡按下时 |

**闩锁是单一汇聚点**：四个触发源共享同一闩锁，弹出沿 = 关卷是统一数据事件。

## 4. 部件规格

### 4.1 换卷弹钮 + 风格拨轮

| 参数 | 规格 |
|------|------|
| 直径 | 10mm（参照快门按钮） |
| 弹起高度 | 5mm |
| 按下深度 | 与顶面平齐或略低1mm |
| 档位 | 3档（暖调/冷调/灰调），120°等分 |
| 刻度 | 红色刻线，对应顶面印刷图标 |
| 表面 | 滚花侧壁（弹起时可见可操作） |

**三节结构**：
1. 弹起高位：拨轮突出，可转动选风格
2. 按下平位：拨轮沉入顶面，锁定不可转
3. 按下再按：无（两节即可）

**锁定机制**：
- 按下后拨轮整体低于顶面，手指自然无法施力
- 无额外锁销，几何本身完成锁定
- 拨轮空转回弹（如结构允许）或完全锁死

### 4.2 过片拨杆

| 参数 | 规格 |
|------|------|
| 位置 | 机身右侧（右手拇指位） |
| 行程 | 与快门释放互锁（1:1） |
| 离合 | 弹起时脱开（失去阻力/空转） |
| 卸力 | 满卷弹出时，拨杆在行程中段卸力 |

**1:1 过片互锁（待确认）**：
- 拨杆行程与快门释放严格 1:1 互锁
- 快门未释放前，拨杆锁死（防重拍）
- 拨杆未到位前，快门锁死（防漏拍）
- 这是计数器正确性的前提

### 4.3 快门

| 参数 | 规格 |
|------|------|
| 状态 | 弹起时锁死，闩下时待发 |
| 释放 | 拨杆到位后解锁 |
| 双曝预防 | 依赖1:1互锁 |

### 4.4 TF卡仓门

| 参数  | 规格            |
| --- | ------------- |
| 联动  | 开门必弹起（机械凸轮）   |
| 闩锁  | 弹起态下按不下去（正阻挡） |
| 卡检测 | 机械在位开关（非电子）   |

## 5. 闩锁架构

### 5.1 核心闩锁

```
        ┌─────────────┐
        │    闩锁      │
        │  （单一点）   │
        └──────┬──────┘
               │
    ┌────┬────┼────┬────┐
    ↓    ↓    ↓    ↓    ↓
  满卷  门   卷终  在线  拨杆离合
  脱扣  联动  钮   拒绝   ↓
                           快门待发
```

**闩锁状态**：
- **闩下**：离合吸合，拨杆有效，快门待发
- **弹起**：离合脱开，拨杆无效，快门锁死

### 5.2 脱扣机构（满卷弹出）

```
第37次拨杆 → 计数轮36位 → 凸轮顶脱扣杆 → 踢开闩锁
  → 弹钮弹出（弹簧储能释放）
  → 离合脱开 → 拨杆行程中段卸力
  → 计数器归零
```

**关键设计**：弹出动能来自拨杆行程，不是电磁铁。电磁铁仅用于在线拒绝。

## 6. 数据模型

### 6.1 卷目录结构

```
DCIM/
  └── ROLL_001/
      ├── 0001.jpg
      ├── 0002.jpg
      ├── ...
      └── 0036.jpg
  └── ROLL_002/
      └── ...
```

- 每卷一个目录，编号顺延
- 卷头记录：按下弹钮时的风格档位、时间戳
- 卷尾记录：弹出原因（满卷/手动/取卡）

### 6.2 文件编号

- 卡内全局顺延，不因卷而重置
- 旧卡插入：新建卷目录，编号继续

### 6.3 风格元数据

- 拍摄时记录风格档位（暖调/冷调/灰调）
- JPEG 不烧滤镜，仅标记默认风格
- App 导出时允许重新选择风格
- 同一张图允许多风格冲印

## 7. 开机对账表

| 开机读到 | 卡状态 | 动作 |
|----------|--------|------|
| 闩下 | 无卡 | 脉冲弹起（在线拒绝路径） |
| 闩下 | 有卡 | 对账：续拍或开新卷 |
| 弹起 | 有卡 | 待闩，按下开新卷 |
| 弹起 | 无卡 | 待闩，按下会被顶回 |

**续拍规则**：
- 卡上最新卷处于开启状态
- 拨轮档位与该卷记录一致
- 两者同时满足 → 续拍，计数器接着走
- 否则 → 收旧卷，开新卷

## 8. 容量策略

### 8.1 预留制

- 按下弹钮时检查：剩余空间 ≥ 最坏帧体积 × 36 + 余量
- 不足 → 闩合后弹出（在线拒绝），屏幕提示"存储卡已满"
- 保证卷不会中途因容量失败

### 8.2 最坏帧体积

- JPEG 内容相关，按最坏情况预留
- 建议：最坏帧 ≈ 平均帧 × 1.5–2

### 8.3 卡满处理

- 卡满 = 最后一卷拍完后的自然状态
- 满卷弹出 → 按下 → 在线拒绝 → 屏幕提示"卡已满"
- 换卡路径与换卷同构：开门 → 弹起 → 换卡 → 关门 → 按下 → 新卷

## 9. 卷终钮

### 9.1 位置与形态

- 位置：机身底板，小凹钮
- 操作：需指甲或笔尖按压，防误触
- 机制：纯机械，直接踢闩

### 9.2 行为

```
按下卷终钮 → 踢闩 → 弹起（离合脱开、快门锁死、计数器归零）
  → 拨轮解锁，可换风格
  → 按下弹钮 → 新卷
```

### 9.3 边界情况

- **0帧合卷**：产生空卷，App侧不显示
- **不满卷结束**：数据无损，卷内照片完整保留
- **关卷原因**：元数据记录"手动合卷"，Contact Sheet可显示

## 10. 状态一致性

### 10.1 断电行为

- 断电期间：按钮自由闩合（纯机械）
- 通电瞬间：固件对账（按钮、卡、拨轮三读数）
- 不一致 → 修正（弹起/闩下）

### 10.2 权威来源

| 状态 | 权威来源 | 说明 |
|------|----------|------|
| 弹起/闩下 | 机械闩锁 | 断电不变 |
| 计数器 | 机械计数轮 | 断电不变，弹出归零 |
| 风格档位 | 拨轮几何位置 | 锁定后不可变 |
| 卡在位 | 机械开关 | 非电子 |

### 10.3 不变量

- **闩下 ⇒ 卡被封在机内**（门互锁保证）
- **弹起 ⇒ 计数器 = 0**
- **锁定 ⇒ 风格档位不可变**
- **弹出沿 = 关卷**（数据事件）
- **闩合沿 = 开卷**（数据事件）

## 11. 工程难点

| 难点 | 说明 | 风险 |
|------|------|------|
| **计数轮凸轮精度** | 36位凸轮要准，35位误脱=丢帧 | 中 |
| **1:1过片互锁** | 拨杆与快门严格互锁，防重拍防漏拍 | 高（待确认） |
| **脱扣力矩** | 释放闩锁需顶住弹簧力，安排在拨杆力矩峰值段 | 中 |
| **旋转基准统一** | 拨轮、顶板、定位盘共用旋转基准，防系统性偏移 | 中 |
| **刻度耐久** | 红线刻槽填漆，顶板图标同样处理 | 低 |
| **门联动正阻挡** | 开门时挡块进入按钮行程路径，物理不可闩 | 低 |

## 14. 术语表

| 术语 | 定义 |
|------|------|
| **卷** | 一次装卡到弹起之间的拍摄会话，36张 |
| **弹起** | 弹钮突出状态，自由态，可换风格 |
| **闩下** | 弹钮吸入状态，锁定态，可拍摄 |
| **弹出** | 从闩下到弹起的动作 |
| **闩合** | 从弹起到闩下的动作 |
| **脱扣** | 闩锁被释放的动作 |
| **离合** | 拨杆与快门之间的传动连接/断开 |
| **1:1互锁** | 拨杆行程与快门释放严格一一对应 |
